What this tool does

This tool builds a custom URL that opens a customised snofl.com site: the parameters you pick here are the page.

Choose an NTAG type if the link is going onto an NFC tag, or leave it on "no NTAG" for a QR code. You can add a title and subtitle, a custom avatar for visitors, a locked or open message, a character limit, hashtags for later discovery on Nostr, and your own relays for where notes get posted. The URL can also be encrypted so only the right password unlocks it (a powerful feature — not for illegal use).

The URL appears as you type. It can be written to a tag with any NFC app or turned into a QR code. There is also a built-in shortener: the long URL is stored on my server, the original is not tracked.

The content

Select words first and a button wraps them; press one with nothing selected and it writes a word you can type over. The name under each button says what it does — no hovering needed. The row scrolls sideways; the fade on the right means there are more commands.

Visitor options

Lets a visitor post a public note (kind 1) from your page — either with the hashtags you chose, or with the suggested message you wrote, which they can edit or not, as you decide below. Anyone on the relays can read that note.

On: a visitor can post a note anyone can find. Off: the page offers only the private room.
